# SP26 External Resources

This page collects the Spring 2026 course-material links used by the personal study track.

## Contents

- [Browsable course-site archive](https://lr2933.github.io/cs61a-spring-2026/): calendar, lecture links, slides, study guides, discussions, labs, homework, projects, and exams.
- [Downloadable source snapshot](https://github.com/LR2933/cs61a-spring-2026): the same materials as a Git repository, including starter archives.
- [Berkeley original course site](https://www-inst.eecs.berkeley.edu/~cs61a/sp26/): canonical SP26 source when the legacy host is reachable.
- [Composing Programs textbook](https://www.composingprograms.com/): the course reading.
- YouTube lecture playlists are linked from the course calendar; Bcourses recordings are available through Berkeley authentication.

## Repository scope

The parent `sp26/` directory stores personal implementations, tests, notes, and progress records. Course files remain at the source links above, with their original attribution and terms.
