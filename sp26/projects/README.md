# CS61A Project Workspace

This directory contains the Spring 2026 project starters, tests, and runtime assets for Hog, Cats, Ants, Scheme, and the optional Scheme Contest.

## Edit and test loop

1. Open the project target shown in [`../ASSIGNMENTS.md`](../ASSIGNMENTS.md).
2. Read the linked project page and its problem phases.
3. Implement one phase at a time in the listed file(s).
4. Run `python3 sp26/tools/course.py test <id>` from the repository root.
5. Narrow the feedback with `python3 sp26/tools/course.py test <id> -- --question <name>`.

The bundled `ok` runner, tests, interpreters, and GUI/runtime assets live beside each project so local checks work from a clean checkout. The optional Scheme Contest is under [`optional/scheme-contest/`](optional/scheme-contest/).
