# CS61A Lab Workspace

This directory contains the Spring 2026 Lab00–Lab11 starter files, tests, and local runtime files.

## Edit and test loop

1. Open the target shown in [`../ASSIGNMENTS.md`](../ASSIGNMENTS.md).
2. Read the linked lab page for the question text and constraints.
3. Implement one question at a time in the listed file(s).
4. Run `python3 sp26/tools/course.py test <id>` from the repository root.
5. Narrow the feedback with `python3 sp26/tools/course.py test <id> -- --question <name>`.

Lab00–Lab07 and Lab09 use Python, Lab08 and Lab10 use Scheme source files, and Lab11 uses SQLite SQL. Lab06 has two edit targets: `lab06.py` and `classes.py`.

The tests are Berkeley's local `ok` tests. They run without login or network access through [`../tools/course.py`](../tools/course.py).
