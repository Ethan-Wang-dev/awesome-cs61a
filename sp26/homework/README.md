# CS61A Homework Workspace

This directory contains the Spring 2026 programming homework starters, tests, and local runtime files.

## Edit and test loop

1. Open the target shown in [`../ASSIGNMENTS.md`](../ASSIGNMENTS.md).
2. Read the linked assignment page for the question text and constraints.
3. Implement one question at a time in the starter file.
4. Run `python3 sp26/tools/course.py test <id>` from the repository root.
5. Narrow the feedback with `python3 sp26/tools/course.py test <id> -- --question <name>`.

HW01–HW06 use Python, HW07–HW09 use Scheme source files, and HW10 uses SQLite SQL. HW11 is a survey/reflection finale with no code runner; its page and status are recorded in [`hw11/README.md`](hw11/README.md).

The tests are Berkeley's local `ok` tests. They run without login or network access through [`../tools/course.py`](../tools/course.py).
