# Contributing

This repository is primarily a personal study record. Suggestions are welcome when they improve reproducibility, documentation, accessibility, or correctness without exposing course solutions.

## Good contributions

- Report a broken official link or an incorrect setup instruction.
- Improve a concept explanation or add a small, original test.
- Propose a clearer directory or maintenance convention through an issue first.

## Do not submit

- Solutions copied from public repositories or other students.
- A completed solution to a current Berkeley assignment.
- Generated code that the author cannot explain and test.
- Credentials, private course material, or unrelated experiments.

For changes to course-facing content, include the official source URL and the date checked. Keep commits focused and explain how the change was verified.
