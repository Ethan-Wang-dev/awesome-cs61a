# CS61A Fall 2026 Supplement

An extension of the Spring 2026 mainline for the AI-era additions in the [Fall 2026 official course](https://cs61a.org/fa26/). Each module connects the new course material to a small, reproducible experiment.

## Coverage

- Gleam, algebraic data types, types, immutable data, and lists
- Coding Agents and the programming workflow around them
- Browsers, Web fundamentals, and application architecture
- Comparisons that explain how these topics extend the Spring 2026 sequence

## Directory map

```text
gleam/              # Typed and immutable data experiments
coding-agents/      # Agent workflows and focused coding exercises
browsers/           # Browser and Web experiments
applications/       # End-to-end application studies
notes/              # Version differences and migration notes
```

## Working method

1. Start from the [Fall 2026 syllabus](https://cs61a.org/fa26/syllabus/) and [update notes](https://cs61a.org/fa26/articles/whats-new/).
2. Record the Spring 2026 concept that the new module extends.
3. Build an original example, run a focused test, and document the result.
4. Keep version-specific observations dated so future offerings can be compared efficiently.
