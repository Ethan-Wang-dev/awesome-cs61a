# CS61A Assignment Workflow Specification

## Goal

Provide a ready-to-edit Spring 2026 CS61A workspace. A learner should be able to open the repository in VS Code, follow one assignment map to the designated source file, and run a local test command for the same assignment.

## Scope

The workspace covers the Spring 2026 programming sequence:

- Homework 01 through Homework 10.
- Homework 11 as a documentation-only finale/survey entry.
- Required projects: Hog, Cats, Ants, and Scheme.
- Optional project: Scheme Contest, kept under an `optional/` path.

The imported material is limited to the files required to edit, test, and run these programming assignments. Videos, slides, discussion PDFs, lab PDFs, and answer files remain external resources. Each imported assignment records its Berkeley source URL and course version.

## Repository layout

```text
sp26/
├── ASSIGNMENTS.md
├── homework/
│   ├── README.md
│   ├── hw01/ … hw10/
│   └── hw11/README.md
├── projects/
│   ├── README.md
│   ├── hog/
│   ├── cats/
│   ├── ants/
│   ├── scheme/
│   └── optional/scheme-contest/
├── tools/course.py
└── tests/test_course.py
```

The starter directories retain the official package structure needed by their tests and runtime assets. Generated bytecode, local backups, credentials, and editor state are excluded from version control.

## Assignment manifest

`sp26/ASSIGNMENTS.md` is the learner-facing index. Every entry includes:

- assignment identifier and type;
- relative directory;
- designated editable file(s);
- one-line learning objective;
- the local test command;
- official instructions and source archive links;
- import/version metadata.

The machine-readable manifest lives beside the CLI in `sp26/tools/assignments.json` so commands and documentation use the same paths. The manifest marks Homework 11 as `documentation` and Scheme Contest as `optional`.

## CLI contract

`python3 sp26/tools/course.py` is a standard-library-only command-line tool.

Commands:

```text
list                         Show every assignment and its edit targets.
doctor                       Validate Python, manifest paths, starter files, and ok.py startup.
test <id> [-- <ok args>]     Run one assignment locally through `ok --local --nointeract`.
test all                     Run all runnable assignments and report a summary.
```

The command resolves paths relative to the repository root, runs each assignment with its directory as the working directory, disables network activity, and propagates test failures through its exit status. `doctor` verifies setup without requiring unfinished exercises to pass. Unknown identifiers, documentation-only entries, missing files, and malformed manifest records produce actionable errors and non-zero exit codes.

## Tests for the workflow

`sp26/tests/test_course.py` tests the workflow itself with Python's standard `unittest` module. It covers:

- manifest schema and unique identifiers;
- every manifest path and designated editable file;
- `list` output;
- `doctor` behavior in the checked-out repository;
- command validation for unknown and documentation-only entries.

The test suite does not contact Berkeley or run the full assignment grader. Assignment correctness remains the responsibility of each assignment's bundled `ok` tests.

## Documentation

`sp26/homework/README.md`, `sp26/projects/README.md`, and the assignment index are concise English guides. They explain the edit/test loop, link to official instructions, and preserve attribution. The top-level bilingual README links to the assignment index as the starting point for code practice.

## Acceptance criteria

1. All scoped starter archives are available under the documented paths, with source files and tests intact.
2. A learner can identify the file to edit from `ASSIGNMENTS.md` or `course.py list`.
3. `python3 sp26/tools/course.py doctor` passes on a clean checkout with Python 3.10+.
4. `python3 -m unittest discover -s sp26/tests` passes on a clean checkout.
5. `python3 sp26/tools/course.py test <id>` executes the corresponding local `ok` runner and returns its result.
6. `python3 sp26/tools/course.py test all` continues through runnable entries and reports per-assignment results.
7. No solutions, credentials, network-only commands, or large course media are committed.
